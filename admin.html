Conectar el panel

El panel publica directo en el repositorio de la página. Para eso necesita un token de GitHub: es la llave. Sin él se puede abrir esta pantalla, pero no se puede cambiar nada.

Sin tildar, el token se borra al cerrar la pestaña. Tildalo sólo en un dispositivo tuyo.

¿Cómo saco el token? (una sola vez)
  1. Entrá a github.com/settings/personal-access-tokens/new con tu cuenta.
  2. Token name: Panel GS9. Expiration: el que quieras (cuando vence, sacás otro igual).
  3. Repository access: Only select repositories → elegí GS9. Sólo ese.
  4. Permissions → Repository permissions → Contents: Read and write. Nada más.
  5. Tocá Generate token, copialo y pegalo arriba.

Así limitado, el token sólo puede tocar los archivos de GS9: ni tus otros repositorios, ni tu cuenta. Si lo perdés o sospechás de algo, borralo en esa misma página de GitHub y sacá otro.
